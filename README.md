# Elly Dickens Oyim — Portfolio

Personal portfolio for my networking and full-stack development work.

## Run locally

```sh
npm ci
npm run dev
```

## Deploy

The site is built with Vite and deployed to GitHub Pages by the workflow in
`.github/workflows/deploy.yml` whenever a commit is pushed to `main`.

The live site is published at
<https://dickens-oyim.github.io/My-Portfolio/>.
